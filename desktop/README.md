# BillFlow Windows Desktop Software (Windows 10 & 11)

This folder contains the native Windows desktop application for BillFlow.

## How to Run:
1. **Double-click `BillFlow.exe`** to launch the desktop application immediately.
2. (Optional) Run `install_desktop_shortcut.bat` to pin **BillFlow** directly onto your Windows Desktop for 1-click launch.

## Features:
- **Dedicated Desktop Window**: Clean native app experience without browser tabs or URL bars.
- **Persistent Offline Storage**: All invoices, clients, inventory, settings, and templates are stored safely in your user profile (`%LOCALAPPDATA%\BillFlow\Data`).
- **Full Printing Support**: Direct print dialog for Laser, Thermal (58mm/80mm), and Dot-Matrix invoices or saving to PDF.
- **Excel & PDF Export**: Instant download of reports, ledgers, and invoice PDFs.
- **Compatible**: Designed specifically for Windows 10 & Windows 11.
